# Blue Yonder (registry name "Jda") — research
Provider/key: workday:jda/jda_careers | company_type: product

What they do: Enterprise supply-chain management software — planning, demand forecasting, warehouse/transportation management, retail execution. Sold to large retailers, manufacturers and logistics providers. The Workday tenant is still on the legacy `jda` slug (JDA Software rebranded to Blue Yonder in 2020); the JD bodies in the registry identify the employer as Blue Yonder throughout. Owned by Panasonic (Panasonic Connect) since 2021.

How they describe themselves: In their own JD text: "Blue Yonder is a leading AI-driven Global Supply Chain Solutions Software Product Company and listed on Glassdoor's 'Best Places to Work'." JDs emphasize "innovation and improving delivery effectiveness", "standardized enterprise solutions for cloud infrastructure and application deployment across multiple products", and "meta-driven systems approach to build robust and scalable systems". Values beyond this were not verified — no company values page was fetched this session.

Size / stage / funding: Large, private, wholly owned by Panasonic. Headcount not verified from a first-party page this session (unverified).

Locations / HQ: HQ Scottsdale, Arizona (unverified from a fetched page). Postings in the registry are concentrated in Hyderabad, Bangalore, Dallas, Palo Alto, plus an 11-location US DevOps/Security req. A JD states the team "comprises of global associates across US, Canada, India, and Germany".

Remote policy: Explicitly not remote for the roles seen. The Staff Software Engineer – Platform Data Cloud JD states verbatim: "Location: Dallas, TX ( Hybrid role) NO REMOTE".

Remote-Canada eligibility: **No — verified negative.** Of 20 relevant postings on record, the US ones are onsite/hybrid (Dallas explicitly "NO REMOTE"), the majority are India-based (Hyderabad/Bangalore), and one is US-citizen-restricted ("DevOps Security Engineer ( US Citizen, Ogden, Utah)"). No Canada-based or remote-Canada req appears in the registry despite Canada being named as a location where the team has associates.

Engineering & tech: Java, Python, Groovy, Node.js, React.js; Spring Boot, microservices, REST APIs; Kafka / Azure Event Hubs, Elasticsearch, Snowflake; Kubernetes/AKS; Azure as primary cloud (ARM templates, Virtual Networks, Azure AD) with AWS/GCP mentioned; CI/CD via Jenkins and GitHub Actions; quality/security tooling SonarQube, Codacy, Checkmarx, GitHub Advanced Security, Black Duck, BlazeMeter, Artifactory, Ansible, Docker. Architecture described as "scalable, resilient, event driven, secure multi-tenant microservices".

Notable / other: Title ladder is unusual and internally inconsistent — "Staff Software Engineer I", "Staff Software Engineer II", and "Lead Software Engineer" are used for what read as mid/senior-level India reqs, so the title words do not map to North American level conventions.

Open relevant roles (sample): Staff Software Engineer - Platform Data Cloud (Dallas); Lead Software Engineer - Java, Microservices, Spring Boot, REST APIs, SQL; Staff Software Engineer - Python, React & Cloud (Hyderabad); Staff DevOps Engineer I (Hyderabad); Sr Gen AI Engineer; Sr Data Engineer - Power BI, SQL, Python & AI/ML.
