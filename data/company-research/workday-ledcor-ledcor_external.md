Engineering & tech: A modern, well-defined enterprise data platform. Stated stack and practices: "a modern **Azure Databricks and Delta Lake** platform using a **medallion architecture** approach"; "production-grade data pipelines using **PySpark** and **Databricks Spark Declarative Pipelines (SDP)**, including Python and SQL transformations across medallion architecture layers"; "metadata-driven ingestion processes using **YAML-based configurations and code generation frameworks** that automate pipeline creation"; "infrastructure-as-code deployments using **Databricks Asset Bundles (DAB)**"; "row-level and column-level security policies using **Unity Catalog**", role-based and attribute-based access control, data classification and governance metadata; "automated data quality checks", validation, regression and reconciliation testing. Modelling depth is unusually explicit: "conceptual, logical, and physical data models using **Information Engineering (crows-foot) notation**, applying **Inmon, Kimball, and Data Vault** methodologies as appropriate", with "business key and surrogate key strategies, SCD patterns, and referential integrity standards". Requirements: bachelor's degree, 6+ years data engineering, 5+ years data modelling with 3NF and dimensional expertise, streaming ingestion, CDC and incremental loads, CI/CD and IaC familiarity. Assets: Unity Catalog, Data Vault 2.0, Databricks or Azure Data Engineer certification, AI-assisted development tools. The role reports to the **Senior Manager, Data & Analytics Platform**.

Notable / other: The JD places real weight on standards and governance — "Contribute to enterprise modeling standards, naming conventions, and data governance practices" and "Contribute to team testing standards and deployment validation practices" — which reads as a mature, process-disciplined data org rather than a greenfield scramble.
