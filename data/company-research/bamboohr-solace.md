# Solace — research
Provider/key: bamboohr:solace | company_type: product

Entity confirmation: this is **Solace Corporation** of Ottawa, Ontario — the event-streaming/messaging
middleware vendor (PubSub+). It is not the US healthcare-advocacy startup also called Solace, nor the
Solace referenced in a Wells Fargo "Lead Infrastructure Engineer - Solace" posting that appears elsewhere
in the registry (that is a bank hiring for skills in *this* company's product). The bamboohr:solace board
and all five live postings are Ottawa-based and match the Ottawa entity.

What they do: Solace builds real-time event streaming and event management infrastructure. Their own
careers page describes "a platform for real-time data streaming across applications, devices, and AI
agents", with named products: **Agent Mesh**, **Event Broker**, **Event Portal**, and
**Micro-Integrations**. The flagship PubSub+ event broker moves events across hybrid cloud, on-premises
and IoT/edge estates, supporting open protocols (MQTT, AMQP, JMS, REST). Customers are large enterprises
in capital markets, aviation, retail and manufacturing — the kind of mission-critical, low-visibility
infrastructure the sector runs on. Agent Mesh is a recent pivot of that event-mesh technology toward
AI-agent orchestration.

How they describe themselves: The careers page emphasizes "a meaningful, authentic" workplace culture
focused on employee support and community involvement, and states "Diversity in all of its forms drives
innovation and growth." Their JDs list a benefits/culture block including, verbatim, "Hybrid-first –
Flexibility is built into how we work, so everyone feels included and empowered." The tone across the
JDs is even and non-hustle; extracted culture reads "balanced" on four of five postings and "sustainable"
on the Senior DevOps role.

Size / stage / funding: Private, Ottawa-headquartered, founded 2001 — a mature ~25-year-old
infrastructure vendor, not a startup. Several hundred employees. The registry's extracted stage labels
across its five postings are inconsistent but revealing: "late_stage" (x2), "growth" (x2) and
"profitable" (x1), which collectively describe an established, self-sustaining enterprise software
business. Historically venture- and growth-equity-backed, long past the runway-dependent phase.

Locations / HQ: Headquarters Ottawa, Ontario, Canada. Every one of the five live engineering postings
carries the location "Ottawa, Ontario, Canada" and the extracted timezone America/Toronto. Global sales
and support presence in the US, EMEA and APAC.

Remote policy: **Hybrid-first, Ottawa-anchored.** Stated on their own JDs: "Hybrid-first – Flexibility
is built into how we work, so everyone feels included and empowered." The careers page adds: "Hybrid
work schedules let 'you do you' so you can do your best work and live your best life." Neither page nor
any JD offers a fully-remote or work-from-anywhere option. The registry's extracted remote_policy is
"hybrid" on all five postings, unanimously.

Remote-Canada eligibility: **Canadian employer, but not remote-Canada.** Pay is quoted in CAD and the
entity is Canadian, so employment is straightforward — but all five live roles are hybrid and tied to
Ottawa with an America/Toronto timezone. Nothing anywhere states remote-anywhere-in-Canada. A
Kimberley, BC candidate cannot satisfy an Ottawa hybrid schedule (~3,500 km, three time zones), so
these roles are effectively closed absent an explicit remote exception.

Engineering & tech: Core infrastructure engineering — event brokers, messaging protocols, distributed
systems, cloud SRE, and now AI/agent integration on top of the event mesh. The five open roles split
into a cloud SRE/DevOps group (Senior Cloud SRE, Cloud SRE, Senior DevOps Engineer) and an AI group
(Senior Software Developer - AI, Principal Software Developer - AI Integration), plus a Datapath role
working on the broker's core data plane. Extracted facets: the two SRE roles report on_call: true with
autonomy: low; the Senior DevOps and Principal AI roles report autonomy: high. The AI roles are
integration/platform work on Agent Mesh rather than model research — genuine agent-infrastructure
territory.

Notable / other: Solace posts salary ranges on its own BambooHR JDs, e.g. the Senior Cloud SRE states
"Expected Salary Range: Expected salary range for this role is from $120,000 to $150,000. The final
offer within this range will reflect the successful candidate's skills and experience." Observed CAD
base ranges by role: Cloud SRE $100–120K; Senior Cloud SRE $120–150K; Senior DevOps $115–140K;
Senior Software Developer - AI $135–165K; Principal Software Developer - AI Integration $155–180K.
These sit below the profile's $160–200K CAD target for everything short of the Principal role.

Open relevant roles (sample): Senior Cloud Site Reliability Engineer; Cloud Site Reliability Engineer;
Senior DevOps Engineer; Senior Software Developer - AI; Principal Software Developer - AI Integration;
Software Developer - Datapath.
