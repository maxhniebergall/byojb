# PayPal — research
Provider/key: workday:paypal/jobs | company_type: product
What they do: PayPal is a global public payments company — the PayPal wallet and checkout network, Braintree, Venmo, and associated risk/fraud, identity and merchant platforms. The live engineering postings sit in fintech backend and platform work: identity platform engineering, backend API security, Venmo cloud infrastructure and DevOps, cloud data infrastructure and data platforms for Venmo, and a fraud-science data platform.
How they describe themselves: No PayPal-owned about/values page was fetched this session (WebSearch budget exhausted; only the Workday board is in the registry). Culture statements are therefore UNVERIFIED here — the JD bodies read as standard large-cap corporate engineering copy without notable hustle vocabulary.
Size / stage / funding: Public company (NASDAQ: PYPL), tens of thousands of employees, mature and profitable. Registry facet extraction consistently marks stage "public".
Locations / HQ: San Jose, California HQ. Other posted US locations: Austin TX, Scottsdale AZ, and several roles listed as "2 Locations"/"3 Locations"/"6 Locations" spanning those hubs.
Remote policy: HYBRID, office-anchored. Every extracted facet across the live postings reads remote_policy "hybrid" with a named US office and America/Los_Angeles timezone. No fully-remote engineering posting appears in the current live set.
Remote-Canada eligibility: NO. All 15 live postings are US-office-anchored, extracted geo eligibility is "us_only" on every role with facets, and pay is quoted in USD under US pay-transparency rules. PayPal does have engineering sites outside the US, but nothing in the live set is Canada-based or Canada-remote. Disqualifying as posted.
Engineering & tech: Python and Java backend, cloud infrastructure and DevOps (Venmo), Kubernetes-era cloud platforms, data platform / cloud data infrastructure, identity and API security, fraud-science data platforms. Ladder is Software Engineer → SE2 → Senior → Staff → Sr Staff → Principal, which maps cleanly onto standard levels.
Notable / other: PayPal posts real ranges under US transparency law and they are competitive: Sr Staff Software Engineer $196,500-$291,500 base + equity; Principal Engineer, Data Platforms (Venmo) $198,000-$323,950 base + equity; Senior Software Engineer - Python $130,500-$212,850 base + equity; Software Engineer / SE2 around $111,072-$171,500. Equity is included at senior levels and above.
Open relevant roles (sample): Sr Staff Software Engineer, BE Python; Principal Engineer, Cloud Data Infrastructure (Venmo Data Platforms); Sr. Software Engineer – Cloud Infrastructure and DevOps (several near-duplicate postings); Staff Software Engineer; Senior Software Engineer - Python; Sr SWE, Fraud Science Data Platform.
