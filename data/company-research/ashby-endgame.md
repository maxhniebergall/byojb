# Endgame — research
Provider/key: ashby:endgame | company_type: product

What they do: Endgame builds "the context graph for every GTM agent" — it ingests calls, deals and playbooks from a company's go-to-market stack and turns them into structured knowledge that both sales/CS humans and AI agents query as a source of truth. Positioning claim from their own JD: "140× faster and a fraction of the cost of throwing raw data at an LLM." Customers named by the company: Monte Carlo, BetterUp, Braze (JD), and Scale, BetterUp, MUX (homepage). Integrates with Salesforce, Gong, Slack, Snowflake, Zoom.

How they describe themselves: "Revenue teams … use Endgame as their source of truth. Instead of context scattered across fifteen disconnected systems, their reps, managers, and CS teams — and the agents working alongside them — all operate from the same structured view of every customer and every deal." On engineering culture, in their own words: "We're an AI-native engineering team. Agentic coding tools are integral to how we build and ship 15-20 times daily, if not more. We build with Claude Code, Cursor, and Copilot… **We move fast, we're not afraid to throw things away, and we keep the bar high because customers depend on us.**" Also "You default to collaborative action. You write, you share early, you make decisions reversible when you can." No formal published values list found. Homepage themes: production-ready AI, security, accuracy, cost efficiency, "reasoning upstream."

Size / stage / funding: ~25 people, "mostly engineers" (their words). Raised $47.5M from EQT Ventures, Menlo Ventures, Upfront Ventures, Unusual Ventures, plus angel executives from Zoom, Stripe, Notion and Airtable. Homepage refers to a Series C. Burn-rate dependent; not profitable as far as anything on record shows.

Locations / HQ: San Francisco (implied by homepage; not explicitly stated on any page fetched — treat as probable, not verified).

Remote policy: The single live posting is tagged "Remote" on the Ashby board. No remote-policy statement found on the company site. Benefits listed are US-shaped: **401k**, US-style health/dental/vision, flexible time off, paid parental leave, education stipend.

Engineering & tech: TypeScript/JavaScript primary ("deep understanding … built and maintained serious systems in it"), Python secondary. Stack signals from the JD: tRPC routes, React components, admin dashboards, a public API layer with authentication, Redis-backed rate limiting and quota enforcement, observability. AI-side: an MCP server and agent tool surfaces — designing tool schemas, managing context windows, tool-call latency; frontier models in production in cloud environments. Data-integration work wiring new sources into the context graph. Ships 15-20 times daily. SOC 2 and ISO 27001 certified. Heavy internal use of agentic coding tools is a stated requirement, not just a perk.

Notable / other: The role is titled "Principal Software Engineer" but the scope described is full-stack and product-facing — frontend features and React components sit alongside API and MCP infrastructure, and "strong product instincts… translate an ambiguous product requirement into deliverable engineering scope" is a listed requirement. They note "forward-deployed engineers" for custom implementations. Application contact: hiring@endgame.io. They state qualifications are "guidelines, not strict requirements."
