What they do: High-performance and AI data infrastructure. DDN builds storage and data platforms for AI training/inference and HPC workloads. The current product focus in the postings is **Infinia**, described as their "AI Data Platform" and as "Infinia Software Defined Storage (SDS)… designed to support multiple client protocols, delivering robust, enterprise-grade storage solutions for cutting-edge use cases", deployed across "on-premises and cloud environments" and operating "at petabyte scale". A large part of the current engineering push is making storage a first-class part of the GPU inference data path, in partnership with NVIDIA tooling.

Engineering & tech: This is unusually deep systems work, and the stack is stated in detail.
- **AI data path / storage (Senior Staff)**: "leverage NVIDIA's NIXL (Inference Transfer Library) alongside the Infinia Data Intelligence Platform to enable ultra-low-latency, high-throughput data movement across GPU, memory, and distributed storage layers, including workloads involving KV cache management and vector database retrieval." Specifics: NVIDIA GPUDirect Storage, RDMA, InfiniBand, NVMe-over-Fabrics; multi-tier storage (NVMe, SSD, object); KV-cache offloading, prefetching and persistence; Linux I/O stack and filesystem internals; Python and/or C/C++ with profiling and performance tuning; benchmarking frameworks; disaggregated compute/storage architectures. Requires 12+ years.
- **AI Engineer (Senior/Staff)**: "Build and optimize LLM serving and inference systems for production environments… Improve performance across GPU and CPU pathways… Work on KV cache, memory, storage, and throughput bottlenecks… Design and scale systems that support RAG and retrieval-heavy AI workloads." PhD "preferred, but far less important than having built serious systems in the real world."
- **Backend / Control Plane**: building the Infinia control plane — "highly scalable, secure, and resilient backend systems that enable centralized orchestration, lifecycle management, policy enforcement, and integration with external systems", API-first with versioned REST/gRPC and full API lifecycle governance, microservices with "strong consistency, fault tolerance, high availability, and low latency at petabyte scale", RBAC and multi-tenancy, IaC-driven policy orchestration, observability (logs/metrics/traces/events), secure-by-design with encryption in transit and at rest and audit logging, disaster recovery and zero-downtime upgrades. Go/C++/Java/Python, Kubernetes, CI/CD. 5+ years.
- **DevOps (Staff)**: Terraform, Python and Bash IaC on GCP "with future plans to expand into other cloud providers"; Kubernetes and ArgoCD; Packer + MaaS for bare-metal Ubuntu imaging; K3s + KubeVirt for self-provisioning VM environments for developers and QA; Infinia itself for S3 storage services; Harbor and Quay for container images; GitHub Enterprise + Actions (DevOps owns the workflow actions); Nexus/JFrog Artifactory build acceleration; Ansible; Prometheus/Grafana; OCI experience "is a plus". Framed explicitly as internal enablement: "Our DevOps engineers are building a seamless, self-service environment to empower developers and QA teams."

Notable / other: The control-plane role states success metrics rather than culture — "Delivery of robust, scalable backend services supporting control plane operations; High-quality, well-documented, and stable APIs with strong adoption; Reduced operational friction through automation… Strong system reliability, performance, and uptime at scale; Secure, compliant services with minimal vulnerabilities and audit issues". The hybrid on-prem + cloud model (bare metal via MaaS alongside GCP) is unusual and technically distinctive.
